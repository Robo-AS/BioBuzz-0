# Gemini / Antigravity Instructions

Please read, follow, and respect the project context, hardware architecture, and coding rules defined in:
@AGENTS.md

### Core Build Commands
- **Assemble TeamCode APK**: `./gradlew TeamCode:assembleDebug` (or `gradlew.bat TeamCode:assembleDebug` on Windows)
- **Run Unit Tests**: `./gradlew test`
- **Check Project**: `./gradlew check`

### Workflow Rules
- Always discuss architecture and implementation details with the user before editing code.
- Consult [`docs/GAME_RULES.md`](docs/GAME_RULES.md) for game-specific scoring, timing, and rules.
